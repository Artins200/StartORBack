# StartORBack — визуальное меню «Пуск» как StartIsBack, но без вмешательства в систему

> **Принцип:** никакой установки в систему. Программа просто рисует красивое меню **оверлеем** поверх панели задач. Закрыл — вернулся обычный Пуск. Не трогает реестр, не подменяет `explorer.exe`, не просит права администратора.

![Preview](https://img.shields.io/badge/платформа-Windows%20%7C%20Electron-blue) ![Безопасно](https://img.shields.io/badge/режим-только%20оверлей-success) ![Node](https://img.shields.io/badge/node-%3E%3D18-green)

### Что умеет

- **Три темы** на выбор — Windows 11 (центр, Mica, скругления), Windows 10 (тёмные плитки), Windows 7 Aero (классика с двумя колонками)
- Поиск по приложениям · Закреплённые · Рекомендуем / Недавние · Все приложения с алфавитом
- Акцентный цвет, прозрачность, размытие (Acrylic/Mica), анимация
- Сканирует реальные ярлыки из `C:\ProgramData\Microsoft\Windows\Start Menu\Programs` и `%AppData%\Microsoft\Windows\Start Menu\Programs`
- Горячие клавиши: `Alt+Пробел` показать/скрыть, клик вне — скрыть, `Esc` — закрыть
- Трей-икона с переключением тем и выходом
- Работает **только пока запущен процесс** — идеально для демо, стримов, презентаций

## Быстрый старт (Windows)

```powershell
# 1. Клонируй
git clone https://github.com/Artins200/StartORBack.git
cd StartORBack

# 2. Установи зависимости
npm install

# 3. Запусти (оверлей появится, иконка уйдёт в трей)
npm start
```

**Как пользоваться:**
1. После `npm start` появится иконка в трее.
2. Нажми **Alt+Пробел** или кликни по иконке — выплывет новый Пуск слева внизу (или по центру в теме Win11).
3. Клик вне меню или `Esc` — скрыть.
4. ПКМ по трею → смена темы, выход.

> **Важно:** родная кнопка Пуск Windows остаётся на месте — мы её не скрываем и не ломаем. Новый Пуск просто появляется **над** панелью задач как окно `alwaysOnTop`. Чтобы вернуть всё как было — просто закрой программу из трея.

### Горячие клавиши

| Сочетание | Действие |
|-----------|----------|
| `Alt + Пробел` | Показать / скрыть StartORBack |
| `Ctrl + K` в меню | Фокус на поиск |
| `Esc` | Скрыть меню |
| Клик вне | Скрыть меню |

### Темы

- **Windows 11** — центрированное, поиск-таблетка, закругления 16px, Mica.
- **Windows 10** — тёмный фон, левый список + правые живые плитки (Погода, Почта, Календарь).
- **Windows 7** — Aero-градиенты, две колонки, синий сайдбар.

Переключение: внутри меню `⚙️` → «Тема меню» или через меню трея.

## Как это безопасно?

- `main.js` **только читает** папки Start Menu, не пишет никуда кроме `localStorage`.
- Нет `autoLaunch`, нет записи в `HKCU\...\Run` без твоего согласия.
- Окно — `transparent:true`, `skipTaskbar:true`, `alwaysOnTop:'pop-up-menu'` — обычный оверлей.
- `shell.openPath()` запускает ярлыки так же, как проводник по двойному клику.

Хочешь автозагрузку — добавь ярлык на `npm start` в `%AppData%\Microsoft\Windows\Start Menu\Programs\Startup` вручную.

## Частые вопросы

**Q: Перехватывает ли Win-клавишу?**  
A: Нет, безопасный перехват Win без драйвера невозможен и ломал бы систему. Используем `Alt+Пробел` — привыкаешь за день. В трее тоже один клик.

**Q: Можно ли скрыть родной Пуск?**  
A: Специально нет — это уже вмешательство. Но можешь сдвинуть панель задач или просто не нажимать родной Пуск, а пользоваться оверлеем.

**Q: Будет ли работать на Windows 7/10/11?**  
A: Да, темы универсальные. На Win7 нет Mica — автоматически фолбэк на Aero.
